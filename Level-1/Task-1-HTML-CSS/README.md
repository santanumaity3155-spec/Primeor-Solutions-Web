# Primeor Solutions — Level 1 Task 1: HTML/CSS

## Description

This project was developed as part of the **Primeor Solutions Web Development Internship — Level 1, Task 1**. It is a clean, professional single-page website built entirely with HTML5 and CSS3, demonstrating fundamental front-end development skills.

## Objective

The goal of this task is to demonstrate understanding of:

- HTML5 semantic markup
- CSS3 styling and layout
- Flexbox-based responsive design
- Navigation menus with hover effects
- Forms with input validation attributes
- Typography, spacing, and visual hierarchy
- Basic accessibility practices

## Features

- **Styled Webpage** — Clear heading, paragraph, image, background colors, and proper spacing
- **Navigation Menu** — Horizontal nav bar with Home, About, and Contact links; hover effects and smooth underline transitions; responsive layout
- **Hero Section** — Eye-catching intro with heading, descriptive paragraph, CTA button, and illustration
- **About Section** — Three feature cards with hover effects using CSS Grid
- **Contact Form** — Name, email, and message fields with labels, focus states, and a styled submit button
- **Responsive Design** — Adapts to desktop (1200px+), tablet (768px), and mobile (375px–430px)
- **Modern UI** — Consistent color palette, clean typography, smooth transitions, and accessible design

## Technologies Used

- **HTML5** — Semantic markup
- **CSS3** — Flexbox, Grid, media queries, transitions, custom properties (CSS variables)

> No JavaScript, Bootstrap, Tailwind, or backend technologies are used in this task.

1. Navigate to the `Level-1/Task-1-HTML-CSS/` folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).

> No server or build tools required — this is a pure HTML/CSS project.
